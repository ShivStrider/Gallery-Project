App Icon Placeholder
====================

Place your app icons here:
- ic_launcher.png (foreground icon)
- ic_launcher_round.png (round icon)

For now, Android will use the default system icon.

To generate proper icons:
1. Use Android Studio's Image Asset tool
2. Or create icons at https://romannurik.github.io/AndroidAssetStudio/
3. Place generated icons in each mipmap-* folder
